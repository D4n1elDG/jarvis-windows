# Jarvis 1.0 per Windows

Assistente vocale per il PC, collegato al tuo account Jarvis.

**[⬇ Scarica l'installer (2 MB)](https://jarvis.danieldg.workers.dev/JarvisInstaller.exe)**: scarica e installa sempre l'ultima versione.

1. Avvia `JarvisInstaller.exe`: si installa nel tuo utente, senza permessi di amministratore.
2. Accedi con **email o nome utente** e **password** del tuo account ([crealo qui](https://jarvis.danieldg.workers.dev/registrati.html)).
3. Jarvis scarica da solo chiavi, memoria e preferenze dall'account.

Gli aggiornamenti si installano da soli. Installer completo (senza download durante l'installazione): `JarvisSetup.exe` nelle [Release](https://github.com/D4n1elDG/jarvis-windows/releases/latest).

Sito: https://jarvis.danieldg.workers.dev
